Importa dati

Carica il file Excel per aggiornare l'inventario: l'export SAP oppure il file di lavoro con ubicazioni e note.

Come funziona lo scambio con il tuo Excel. Le quantità (colonna Utilizz. liber.) vengono sempre prese dal file. Ubicazione e note vengono lette dal file solo se la cella è compilata: una cella vuota non cancella quello che hai scritto nell'app. Per portare sul PC le note scritte nell'app usa Inventario → Esporta inventario.
